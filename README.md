<h1 align="center">WizHax 1.21.11</h1>

## How to install
1. Download the latest .jar from [releases](https://github.com/VadimTotok/WizHax/releases)
2. Drag it into `~/.minecraft/mods` folder
2. Launch Minecraft With [Fabric](https://fabricmc.net/) and [Meteor Client](https://meteorclient.com/)
4. Access modules via Meteor Client GUI

## Modules

| Module | Description |
|---|---|
| AdvancedItemESP | ESP module that highlights only certain items. |
| AFKVanillaFly | Maintains level Y-flight with fireworks and smooth pitch control. |
| AntiInteract | Prevents you from interacting with certain blocks such as beds and respawn anchors. |
| AutoArmor | Automatically equips armor. |
| AutoEXP | Automatically repairs your armor and tools in PvP. |
| AutoLog | Automatically disconnects under configured conditions such as low health, low armor durability, portal time, position, totem pop, or server not responding. |
| AutoPortal | Automatically builds and lights a Nether portal. |
| AutoSign | Automatically fills and updates signs. |
| AutoTorch | Automatically places torches when block light is too low. |
| CaveAir | Highlights cave air blocks around you. |
| CollectibleESP | Highlights collectible items in item frames and banners. |
| DynamicFPS | Limits FPS when the game is unfocused. |
| ElytraGlide | Cycles between climbing to target Y with fireworks and gliding down to min Y at a fixed pitch. Disconnects and pings Discord when out of fireworks. |
| ElytraSwap | Cycles elytras while repairing. |
| InvCleaner | Automatically drops selected items when they appear in your inventory. |
| KillEffects | Displays effects when entities die. |
| MineESP | Renders a box at blocks being mined. |
| Miner | Full auto miner with tool swap, mending, unload, foundation, and escape trap. |
| MobGearESP | ESP module that highlights mobs likely wearing player gear. |
| NoHurtCam | Removes the hurt camera tilt and shake effect when taking damage. |
| Particles | Customizable particles such as totem pops. |
| PortalPatternFinder | Scans for the shapes of broken or removed Nether portals within cave air blocks in caves and underground structures in 1.13+ chunks. May be useful for finding portal skips in the Nether. |
| Printer | Automatically prints blocks from the loaded Litematica schematic. |
